Concept A, Console

One token system, three characters

간격, 라운드 스케일, 그림자, 타입 스케일, 모션, 의미 색은 세 시안이 함께 씁니다. 브랜드 색, 중립색의 색조, 서체, 기본 라운드만 시안마다 바뀝니다. 위의 탭으로 시안과 테마를 바꾸면 이 페이지 전체가 해당 토큰으로 다시 그려집니다.

01 / brand

Brand

시안별로 바뀌는 소수 토큰입니다. shadcn의 --accent는 hover 면이라서 브랜드는 --brand-*로 따로 둡니다. 대비비는 지금 화면의 실제 계산값입니다.

02 / neutral

Neutral ramp

명도(L)와 채도(C)는 세 시안이 같고, 색조만 --neutral-hue로 브랜드 쪽에 살짝 기웁니다. 순수 회색을 쓰지 않습니다.

--n-450은 라이트 테마의 입력 경계(3:1), --n-600은 보조 텍스트(4.5:1)를 위해 넣은 단계입니다.

03 / surface

Surface and text

컴포넌트는 단계 번호 대신 역할 이름을 씁니다. 라이트에서는 카드가 배경보다 밝고, 다크에서는 카드가 배경보다 한 단계 떠 있습니다.

--bg-subtle (sidebar)

04 / semantic

Semantic colors

브랜드와 분리된 상태 색입니다. 각 색은 fg, bg, border, solid, solid-fg 다섯 단계를 가집니다. B는 info를 하늘색 쪽으로, C는 warning을 주황 쪽으로 옮겨 브랜드와 겹치지 않게 했습니다.
